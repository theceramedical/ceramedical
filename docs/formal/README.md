# CERA formal documentation library

This directory contains the canonical client and development documents collected
with the CERA platform source workspace. Editable DOCX files and rendered PDFs
are separated so the team can find the correct format quickly.

## Platform pack

`platform-pack/docx` contains the ten-document CERA platform pack:

1. Documentation index
2. System design specification
3. Solution architecture design
4. Technology stack and open-source strategy
5. Brand and digital UI design system
6. Third-party baseline cost schedule
7. DevOps, security, backup and operations plan
8. Ten-working-day implementation plan
9. QA, UAT, launch and handover checklist
10. Scope, responsibilities and change control

## Decision pack

`decision-pack/docx` and `decision-pack/pdf` contain matching editable and
rendered versions of the architecture/server recommendation, domain/DNS/email
recommendation, project estimate, three-developer delivery plan, risk and
discovery checklist, and executive decision memo.

## Final deliverables

`deliverables/docx` and `deliverables/pdf` contain matching versions of:

- Full platform product requirements document
- CI/CD handbook
- Baseline infrastructure agreement
- Developer 01 product/frontend ten-day plan and execution manual
- Developer 02 commerce/integrations ten-day plan and execution manual
- Developer 03 platform/security/release ten-day plan and execution manual

The Markdown engineering references one level above this directory remain the
working source for architecture decisions, branch routines, environment rules
and operational runbooks.
